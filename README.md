# Task Reminder

Task Reminder adalah website sederhana untuk membantu pengguna mengelola tugas kuliah. Pengguna dapat menambahkan tugas berdasarkan mata kuliah, mencatat tenggat waktu, menandai tugas yang telah selesai, serta memantau progres penyelesaian. Data tugas disimpan di browser sehingga tetap tersedia saat website dibuka kembali pada perangkat yang sama.

Website ini dibuat menggunakan HTML, CSS, dan JavaScript, dengan tampilan responsif untuk desktop maupun perangkat seluler.

## Struktur File

- `index.html` berisi struktur halaman.
- `styles.css` mengatur tampilan dan responsivitas.
- `script.js` menangani data, interaksi, dan penyimpanan tugas di browser.
- `Image/` berisi aset gambar dan favicon.

Buka `index.html` di browser untuk menggunakan aplikasi.
